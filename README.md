# HROKI

HROKI is a tool for consolidating `.json` playerlists that use the **TF2BD playerlist schema**. It makes it easy to combine multiple playerlists, add custom marks, and prepare playerlists for use with **TF2BD** or **Shadefall**.

HROKI is especially useful for transitioning from TF2BD to Shadefall.

For best results, use Hroki alongside Teltta's **markgroup** tool:

https://github.com/Teltta/hackerpolice-stuff/blob/main/markgroup/compiled/markgroup.exe

## How to Use

### 1. Download the HROKI HTML file

As HROKI is a simple program, it can easily be ran as an HTML file with no further requirements. 

### 2. Prepare Your JSON Files

Gather the `.json` files you want to consolidate. These can include:

- Your own custom playerlists
- Playerlists created by others
- `.json` files generated by Teltta's `markgroup`

All files must use the **TF2BD playerlist schema**.

### 3. Load Your Files

In HROKI, click **Select Files** and add all of the `.json` files you want to merge.

### 4. Add Marks

Assign the desired attributes to each loaded file.

HROKI supports both **preset marks** and **custom marks**.

> **Note:** Custom marks are case- and spelling-sensitive. For example, `Cheater` and `cheater` will be treated as two separate marks.

### 5. Merge the Files

Rename the output as desired, then click **Merge Loaded Files**.

Check the console log for repeated SteamIDs. HROKI will show you each list that they are in and what marks they will receive.

This also gives you an opportunity to catch mistakes before exporting the final playerlist.

### 6. Export the Playerlist

Click **Export Output**.

The resulting `.json` file will be saved to your **Downloads** folder.

## Using the Output

### TF2BD

1. Add the exported `.json` file to your TF2BD config file. This should be in `TF2BD > cfg`.

### Shadefall

1. Upload the exported `.json` file to GitHub.
2. Open the uploaded file and click **Raw**.
3. Copy the URL from the address bar. It should begin with `raw.githubusercontent.com`.
4. In Shadefall, go to **Settings** and scroll down to **COMMUNITY PLAYERLISTS**.
5. Paste the raw GitHub URL into Shadefall.
